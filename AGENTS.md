# Namegarage public skills

Publish only the public catalog instructions. Keep MIT-0. Do not include private
portfolio data, credentials, operator instructions, transaction authority or
cross-site references. Search descriptions reach Namegarage; preserve the
privacy guidance and the difference between a missing listing and registration
availability. Null prices remain offer-only.

Keep HTTP/OpenAPI, MCP, the SDK and skills coordinated. A new public feature or
changed behavior requires checking nikolay/liquidate, namegarage/sdk and this
repository, updating every affected source, exact versioned install examples,
release.json, a separate Developers changelog entry and an engineering Dev blog
post. Explain compatibility for any unchanged component version. The canonical
website template and this SKILL.md must produce identical bytes. Run
python3 tools/check_release.py and the central tools/check_public_release.py
with explicit local SDK and skill paths.

Use immutable new releases, owner-requested Muse Code or Antigravity review,
and focused local checks. Keep Actions disabled. A release remains pending until
GitHub/tag bytes, ClawHub's scan and ordinary anonymous install, and the skills.sh
listing and ordinary anonymous install are verified against the exact digest.
Do not use force or bypass security holds. Do not run ordinary production
searches, forms or purchases as tests.
